Create the source code for an application where the main objective of the system is to create a multimedia sharing service for images (view, download, upload), videos(view, download, upload) and files (download and upload).

# Frontend (create the project on root folder frontend)

1. Should be a web page, an android app and an ios app using Flutter and Dart.
2. The user must be authenticated by a login screen, it must have an option to sign up. The informarion needed are username and password.
3. The application must run from the IDE.

# Frontend 2
1. The application starts with the login screen, when logged successful should take the user to the main screen.
2. In case user enter in signup screen, after signup, it should take user back to the login screen. 
3. The main screen should be infinite scroll, always show a floating search text box at the bottom right of screen, a floating filters icon button at bottom right of the screen and a floating configuration icon button at bottom roght of the screen.
3.1 The screen must be filled with a list of full width itens with the title of the group and a line as separator.
3.2 Inside these groups should be filled with squares of images in grid format with 3 columns. 
4. The configuration screen will be a list of storage itens (full width), each item separated by a line. At the bottom with the following floating icon buttons align to the right: logout, synchonize and back.
5. All the screens must have the dark gray background and text and buttons on orange (meaning danger), green lime (meaning confirm action) and cyan(colors) colors. 

Examples of data for item 3 (based in list of backend\src\main\java\com\mms\dto\MediaResponse.java):
    - Title: January/2024 (Number of squares equals to 7)
    - Title: February/2024 (Number of squares equals to 12)
    - Title: April/2024 (Number of squares equals to 2)
Examples of data for item 4:
    - Type: AWS, Name: ABC123, Updated: 30/10/2024, Size: 345 mb, Itens: 23
    - Type: Server, Name: home,Updated: 29/10/2024, Size: 1345 mb, Itens: 543

# Backend (create on folder backend)

1. Should use Spring Boot and MVC components, written on Java 24. 
2. Should use Postgres database to store metadata from files.
3. All data will be accessed using rest endpoints.
4. The endpoints must be authenticated using JWT token.
5. The source code files should be at the folder "backend".

# Database (create the sql files on folder database)

1. Should use postgres database
2. create the tables as need by backend defition

# Files storage

1. All the files uploaded will be stored using Minio (https://github.com/minio/minio) or AWS S3 (https://aws.amazon.com/s3/)
2. The configuration to the minio or s3 bucket should be set on the configuration file of backend.
