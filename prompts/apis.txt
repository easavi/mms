Media API - Updated Implementation

api/media
    ?group=<a string where could be 'month', 'day' or 'tag', default value is 'month'>    
    &sortDirection=<string where could be 'asc' or 'desc', optional, default is 'desc' >
    &start=<date in format YYYY-MM-DD, optional>
    &end=<date in format YYYY-MM-DD, optional>
    &type=<a string where could be 'image', 'video' or 'file', optional, leave blank for all>
    &tags=<list of strings, where each string represents a tag, optional, leave blank for all>
    &page=<number of the page>
    &size=<number of records on page>

✅ IMPLEMENTED CHANGES:

1. Updated MediaController.java:
   - Simplified main GET /api/media endpoint to use new parameter structure
   - Removed deprecated endpoints (search, filter, statistics, validate-filter, grouped)
   - Kept only essential endpoints: CRUD operations and upload

2. Updated MediaService.java:
   - Added new filtering method that supports media type filtering
   - Enhanced filtering logic to handle all combinations of filters
   - Always sorts by createdAt field as specified

3. Updated MediaRepository.java:
   - Added new query methods for media type filtering
   - Added combination queries for media type + date + tags

4. Updated Frontend (Flutter):
   - Simplified MediaService to match new API
   - Updated ApiConfig to remove deprecated endpoints
   - Updated getAllMedia method to use new parameters

5. Updated Documentation:
   - Updated README.md with new API specification
   - Documented all query parameters and their usage

✅ REMAINING ENDPOINTS:
- POST /api/media (create)
- POST /api/media/upload (upload)
- GET /api/media (list with filters) ⭐ NEW IMPLEMENTATION
- GET /api/media/all (get all without pagination)
- GET /api/media/{id} (get by ID)
- PUT /api/media/{id} (update)
- DELETE /api/media/{id} (delete)

✅ KEY FEATURES:
1. Media will always be sorted only by the field createdAt ✓
2. If 'start' and 'end' is blank, then should bring all the media ✓
3. Tags could have many tag values ✓
4. New 'type' parameter for filtering by media type ✓
5. Date format is YYYY-MM-DD as requested ✓

Example requests:
- GET /api/media?page=0&size=20 (basic pagination)
- GET /api/media?type=image&sortDirection=asc (images sorted ascending)
- GET /api/media?start=2024-01-01&end=2024-12-31 (date range)
- GET /api/media?tags=vacation,photos&type=image (tagged images)
- GET /api/media?group=day&start=2024-08-01&end=2024-08-02&type=video (daily videos)
